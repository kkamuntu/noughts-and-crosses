# Noughts and Crosses Game

A 2-player noughts and crosses game

## How to play

1. Enter player names when prompted
2. Take turns to enter the number of the square you wish to play in (see map below)
3. The result of the game is displayed at the end of the game

### Game map:

1|2|3
-+-+-
4|5|6
-+-+-
7|8|9
